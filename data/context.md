## 1. Module Overview & Role
The `data/` directory provides persistent local storage for the offline datasets utilized across the **Bitcoin Traffic Monitor (Flashmen)** pipeline. It isolates raw offline assets from application code:
- Offline IP geolocation databases.
- Synthetic and benchmark traffic dumps used for local testing, integration checks, and CI evaluation.

## 3. What Has Been Implemented By This Point

### 3.1 MaxMind GeoLite2 Storage (`data/geolite2/`)
- Active binary file `GeoLite2-City.mmdb` is installed in `data/geolite2/`.
- Used by `backend/services/ingestion.py` for offline IP-to-country enrichment.
- If the binary file is absent or an unmapped/private IP is queried, the ingestion service gracefully falls back to `"UNKNOWN"` country codes without halting parsing.

### 3.2 Synthetic Test Dataset (`data/synthetic/sample_traffic.csv`)
- Pre-generated 50-row benchmark dataset generated using `ml/dataset_gen.py`.
- Fully conforms to the 14-column contract:
  - `timestamp`: ISO-8601 formatted timestamps
  - `src_ip`, `dst_ip`: Synthetic IPv4 addresses
  - `src_port`, `dst_port`: Standard (8333, 8332, 18333) and ephemeral ports
  - `txid`: 64-character hex strings
  - `input_addresses`, `output_addresses`: Mock wallet address hashes
  - `input_amounts`, `output_amounts`: Numeric BTC volumes
  - `src_asn`, `dst_asn`: Autonomous System numbers (e.g. `AS13335`, `AS15169`)
  - `src_country`, `dst_country`: ISO-2 country codes
