---

## 1. Module Overview & Role
The `data/` directory provides persistent local storage for the offline datasets and databases utilized across the **Bitcoin Traffic Monitor (Flashmen)** pipeline. It isolates raw offline assets from application code:
- Offline IP geolocation databases (`GeoLite2-City.mmdb`).
- Synthetic and benchmark traffic dumps used for local testing, integration checks, and CI evaluation (`sample_traffic.csv`).
- Local SQLite database (`alerts.db`) used as default persistence when running without Docker or PostgreSQL.

## 3. What Has Been Implemented

### 3.1 MaxMind GeoLite2 Storage (`data/geolite2/`)
- Active binary file `GeoLite2-City.mmdb` is located in `data/geolite2/`.
- Used by `backend/services/ingestion.py` for offline IP-to-country enrichment.
- If the binary file is absent or an unmapped/private IP is queried, the ingestion service gracefully falls back to `"UNKNOWN"` country codes without halting parsing.

### 3.2 Synthetic Test Dataset (`data/synthetic/sample_traffic.csv`)
- Benchmark dataset generated using `ml/dataset_gen.py`.
- Fully conforms to the 14-column contract:
  - `timestamp`: ISO-8601 UTC timestamps
  - `src_ip`, `dst_ip`: Synthetic IPv4 addresses
  - `src_port`, `dst_port`: Standard (8333, 8332, 18333) and ephemeral ports
  - `txid`: 64-character hex strings
  - `input_addresses`, `output_addresses`: Mock wallet address hashes
  - `input_amounts`, `output_amounts`: Numeric BTC volumes
  - `src_country`, `dst_country`: ISO-2 country codes
  - `pattern_type`: Evaluation ground truth (`normal`, `peel_chain`, `mixer`, `sybil_relay`)

### 3.3 SQLite Persistence (`data/alerts.db`)
- Created automatically on first ingestion or startup if PostgreSQL is not detected.
- Stores `alerts` table with `id`, `entity_type`, `entity_id`, `risk_score`, `confidence`, `reason`, and `shap_explanation` (JSON column).

## 4. Setup & Generation Instructions

> [!IMPORTANT]
> Always execute data generation commands from the **repository root (`flashmen/`)**.

```bash
# 1. Activate Python virtual environment
# Windows (PowerShell):
.\.venv\Scripts\Activate.ps1
# Linux:
source .venv/bin/activate

# 2. Generate 500-row synthetic traffic dataset
python -m ml.dataset_gen --output data/synthetic/sample_traffic.csv --rows 500

# 3. Generate larger stress-test dataset (e.g. 5,000 rows)
python -m ml.dataset_gen --output data/synthetic/stress_traffic.csv --rows 5000
```
